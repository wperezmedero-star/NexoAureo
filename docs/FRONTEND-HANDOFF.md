# Entrevista funcional: notas de integración

- El resumen en vivo solo refleja datos declarados; no ejecuta ni anticipa el motor.
- El indicador de preparación valida estructura y campos pendientes, no elegibilidad ni producto.
- El panorama privado organiza hasta ocho análisis recientes. No compara personas, aseguradoras, productos ni cotizaciones.
- El panorama recibe calidad, pendientes y precauciones directamente en el listado. Los expedientes antiguos o incompatibles conservan una consulta de detalle como respaldo honesto.
- No se usa almacenamiento del navegador. Si la página se cierra antes de guardar, el borrador no se conserva.
- Los bloqueos universales provienen del servidor. Los mensajes sobre campos incompletos pertenecen únicamente a la interfaz.
